# Licensed environment source staging

Place the unpacked, licensed Warden's Hollow environment package in
`wardens-hollow-pack/` alongside its `LICENCE.txt`.  Do not put downloaded
archives, duplicate exports or old pack revisions here.  Runtime-ready Godot
assets are generated into `game/assets/environment/warden_hollow/` only after
the source formats, scale, licence and material maps pass the intake contract in
`docs/ENVIRONMENT-ASSET-INTEGRATION.md`.
