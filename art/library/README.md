# Reusable RPG art library

This collection is for later RPG development. It is not imported into the live game.

Read [the research, priorities, biome coverage and paid bookmarks](../../docs/OPEN-ASSET-LIBRARY.md).

`source/` contains the current unpacked original art and its licenses. `MANIFEST.json` records exact origins/hashes and glTF contents; `LICENSE-EVIDENCE.json` records publisher license checks; `BLENDER-INVENTORY.json` records read-only inspection. `security/` contains Defender scan receipts. `VALIDATION.json` and `PRESERVATION.json` record final integrity checks.

Collected 11 October 2026: 34 collections, approximately 515 MB (491 MiB), 791 original art/license files and 601 glTF/GLB scenes. Most of the original 30 collections are CC0; spider, crab, and fox animations require CC BY attribution.

User-authorized Quaternius additions: 12 animated animals and 50 animated monsters, both with editable Blender sources and glTF; 128 Fantasy RTS and 72 Pirate glTF models. See [Quaternius priorities and exact file links](QUATERNIUS-PRIORITIES.md). Retain supplied legacy CC0 declarations and current QAL terms; conservatively keep raw Quaternius assets private to this project's collaborators. These four packs are an explicit exception to the open-license preference.

Downloaded code was excluded. Open Blender sources with auto-execution disabled. Scan results detected no threats; they are not an absolute guarantee. Do not delete this reusable source library as an obsolete release or automatically copy it into `game/`.
