# Coastal Foundation

A small pixelated 3D exploration prototype for Windows, built from the earlier coastal character artwork.

Double-click **CoastalFoundation.exe**. The executable includes the game data; no engine or asset editor is needed to play. If using the ZIP, extract it before starting the game.

## Controls

| Control | Action |
| --- | --- |
| WASD or arrow keys | Walk in four directions |
| E, Space, or Enter | Talk, read signs, continue dialogue |
| F5 / Save button | Save your place |
| F9 / Load button | Load your saved place |
| Fine pixels / Chunky pixels | Switch visual pixel density |
| H / Help button | Open help |
| Escape | Close dialogue or help |
| F11 | Toggle fullscreen |

Follow the path north from Coastal Path to Village Green. Follow it south to return. Buildings, signs, NPCs, and water block movement. Gameplay stays on a horizontal plane.

Saves are local to this Windows account, in `%APPDATA%\Godot\app_userdata\Coastal Foundation\save-v1.json`. Save explicitly before closing the window. Verification uses a separate temporary save file.

This is a reusable exploration foundation with two sample areas, shared character animation, dialogue, and saving. The earlier girl is represented by a simplified rigged model with a separate sword carried on her back.
