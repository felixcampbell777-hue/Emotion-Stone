## Reproduced faults and fixes

The old slope fixture left the player at the final player route while testing the first two boar routes. The boars correctly slept beyond 60 m. Keeping the player eight metres to the side of each boar route fixes the fixture without changing the production sleep budget or thresholds.

Several historical fixtures assumed `update_packs()` immediately created enemies. Production intentionally enqueues at most one model per tick. Focused setup now advances the actual bounded production queue. The boar combat fixture also needs `_refresh_simulation()` after its frozen direct respawn sequence; setting only `input_enabled` no longer restores the separate simulation gate.

Historical guild/boss assertions expected two merchant buttons and 250 Elder XP. Current contracts include normal new-weapon/arrow offers and 500 repeatable Elder XP plus an unpaid one-time 1,000 bonus. Elder stone/slam fixtures now check before and after the actual normalized contact markers instead of ticking an insufficient fixed duration.

Independent checks found three production persistence/transport defects: backup write failure truncated the previous checkpoint; JSON integer-to-float conversion changed lineage hashes; and checkpoint ancestry hashed a profile after mutation instead of its accepted predecessor. Owners repaired these and independent storage/portability checks pass. A subsequent actual process test caught unsupported dynamic snapshot decompression; matching DEFLATE fixed snapshot delivery.
