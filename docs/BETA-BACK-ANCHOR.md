The user rejected the straps and requested a total reset, possibly a simple back anchor. Beta now uses one rounded leather pad instead of the crossed strips, long bridges and wide saddles. Two short rounded steel spring clips retain the broad blade. The pad lies mostly near the center of the back, just above the existing belt. It is an original game attachment rather than a claim about a historical carry system. No new asset or downloaded code was used.
