# Beta locomotion and animated first-person view v0.28.0

The user rejected the high-stepping walk and asked for preset human movement before more manual animation. The trusted free [Quaternius Universal Animation Library Standard](https://quaternius.itch.io/universal-animation-library) supplies Walk_Loop, Jog_Fwd_Loop and Sprint_Loop. The creator page and supplied License.txt state CC0; existing user authorization for Quaternius covers the site's current license ambiguity. No paid kit was purchased. CMU mocap and Blender's contact/down/passing/up workflow were researched; the creator's game-ready in-place clips were selected for this sixteen-bone presentation.

Source intake is art/library/source/quaternius-human-motion/INTAKE.json: creator upload 17958403, archive/selected-data SHA256 hashes and successful Windows Defender archive/extracted-file scans. Only the in-place Godot GLB, README and license were extracted. No donor code, project, plugin or installer was executed. tools/sample_human_motion.gd uses native glTF parsing to sample 121 poses per cycle into game/content/beta_locomotion_samples.json. Raw mannequin/pack are not shipped. Artists: Quaternius and Gonzalo Furnier.

beta_gait.gd fits the samples to actual personal leg lengths with two-bone IK. Walking uses a 21cm foot track, about 3.2cm maximum ankle lift, nearly level soles and small weight shifts. Running uses the distinct sprint, with flight and backward heel recovery; drawn running uses the jog, a shorter stride and existing sword-burden upper-body pose. Spine/head counter-motion and ordinary arm swings derive from the preset. No bone is stretched. The old constant crouch and 11cm walk lift are removed. Movement blends over .16s; running blends over .20s.

Tuning lives in beta.json locomotion. Beta ordinary walk is 1.55m/s; drawn walk remains 1.25m/s, sprint 4.6m/s and drawn sprint 2.4m/s before existing bonuses/slowdowns. Alpha movement remains unchanged. Stride phase advances once in actor physics from actual horizontal distance moved, including collision/terrain limits; rendering never advances it. Overlays freeze the presentation blend. Existing clip IDs, combat clocks, private saves, shirt art and canonical/personal sources remain intact. The separate locomotion bank does not replace combat clips.

First-person uses the live rendered rig's head relative to its bind for eye position and rotation, including pitch/roll and the full root spin. Mouse yaw stays independently saved. Right/down and left/up input are tested against rendered screen axes. Eye collision still uses scenery/canopy layers 1 and 8. Head/body culling, live arms/steel, parry and pointer/menu gating remain intact.

Run verify-beta, verify and verify-windows. Inspect native beta front/side sheets for walk/run and burden walk/run. Native camera evidence includes look-left/look-right and five actual third-combo spin views; standard combat evidence retains water, lance, parry and burden-walk. Headless checks alone do not establish visual correctness.
