# Floor Two island reference

The authoritative code registry is `floor-02-island-codes.json`. All 101 current islands have stable F2-prefixed codes. Initially, letters A-K run west to east and rows 1-11 run north to south. Codes belong permanently to the island ID, even after relocation. Do not reassign codes when editing coordinates.

Use an island code for placements and both endpoint codes for a crossing. Arrival is F2-H11. The four other refuges are F2-D2, F2-I4, F2-B8 and F2-D11. These are editing references only; do not add labels to the gameplay map. The existing no-location-label/no-undiscovered-marker preference remains.
